# 0018. Public API and the backward compatibility promise

- Status: proposed
- Date: 2026-11-01
- Amends: [0010](0010-public-api-of-core-0-1.md) (injectable collaborators), [0015](0015-token-budget-batching.md)
  (`batcher` becomes `tokenEstimator`), [0017](0017-term-checks-after-translation.md) (`termChecker` is not injected)

## Context
1.0 freezes the public API (ROADMAP). Before this decision, 81 of 93 classes in `src/` carried no `@internal`, so
Semantic Versioning would have covered the inside of the pipeline too (`Html\Segmenter`, `Provider\Llm\PromptBuilder`,
`Provider\Llm\Bridge\TransportFailure`, …), and every refactoring of those would have been a major release. ARCHITECTURE
§4 described the stable surface, but nothing marked or checked it (#76). Integrations also need the core's quoting of
untrusted text, which was internal (#87).

Alternatives considered:
- *Keep the pipeline collaborators injectable (ADR-0010)*: makes `Segmenter`, `Reassembler`, `StructureValidator` and
  every type in their signatures public, for a use case nobody has. Rejected.
- *Move internals into an `Internal` namespace*: a large rename for the same effect as `@internal`. Rejected.

## Decision
- Every class in `src/` belongs to one tier:
  - **Public API**: the classes an application uses: `HtmlTranslator`, its options, results, profiles and
    exceptions (including `Exception\UntrustedText` for integrations), `SkipRules`, `TranslatableAttributes`,
    `CharacterTokenEstimator`, the providers and chat-model adapters with their configs, `RetryPolicy` and
    `UsleepSleeper`.
  - **Extension points**: the ports (`TranslationProviderInterface`, `CacheableProviderInterface`,
    `ChatModelInterface`, `TokenEstimatorInterface`, `SleeperInterface`), every type in their signatures (batches,
    units, results, chat requests and responses), the tools a provider or adapter in another package needs to behave
    like the bundled ones (`Domain\UnitText` with `UnitTextToken` and `UnitTextTokenKind` to read and write unit text
    with pseudo-tags, ADR-0003/0008; `Provider\Llm\Bridge\Retrier` with `RetriedResponse` and `TransportFailure` for
    transport retries, ARCHITECTURE §6.8) and the `Testing` namespaces (contract test cases, fakes).
  - **Internal**: everything else, marked `@internal` on the class or member. No promise; may change in any release.
- The promise covers the public API and the extension points. A public signature never refers to an internal class.
- A minor version may add classes, optional named parameters (positional order is not part of the API, ADR-0010),
  methods of `final` classes and cases of public enums (code that matches a library enum exhaustively must handle
  new cases). A contract test case may gain tests that check already documented behaviour.
- Only a major version may add a method to an interface (a minor adds a new interface instead), remove or rename
  anything, or change a signature incompatibly. Removals are deprecated (`@deprecated`) in a minor version first.
- Only ports and configuration are injected. A public class that composes internal collaborators creates them
  itself from that configuration: `HtmlTranslator` (loader, segmenter, validator, term checker, reassembler, batcher
  from `skipRules`, `translatableAttributes` and `tokenEstimator`) and `LlmTranslationProvider` (prompt builder,
  response parser). This replaces ADR-0010's list of injectable collaborators.
- `tests/Unit/Architecture/public-api.txt` lists every public and extension-point class with the signatures of its
  public members (protected too, for classes that are not `final`), generated by reflection. `PublicApiTest` fails on
  any difference and on a public signature that refers to an internal class; `php scripts/dump-public-api.php`
  regenerates the file, so every API change is a visible diff in review.

## Consequences
- The pipeline can be refactored in any release; only the snapshot file says what callers may rely on.
- Tests cannot replace an internal collaborator of `HtmlTranslator`; they configure it through its public parameters
  or test the collaborator directly.
- A new parameter or class must be classified when it is added; the snapshot diff makes it visible in review.
- The snapshot covers signatures, not behaviour: documented behaviour stays protected by the tests and the CHANGELOG.
  The contract test cases check structure with the internal `StructureValidator`: their strictness follows the
  documented pseudo-tag rules (ADR-0003), and tightening it is a behaviour change for providers in other packages
  that goes in the CHANGELOG.
- The snapshot test reads native types by reflection and PHPDoc types (`list<X>`, `@throws`) by class name in the
  type tags of public members; prose in docblocks is not checked.
